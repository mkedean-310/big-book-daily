# The Story of How We Recovered

A daily study of the Big Book, made as an installable phone app (PWA).

- 204 daily readings, from the Title Page through Doctor Bob's Nightmare, each with the book quote, reflections and questions
- Readings: how to use the study, the circle and the triangle, every prayer from the daily posts, twelfth-step directions, and closing reflections
- Self-paced: Today, Previous/Next, Mark complete, Contents, and search
- Private journal under each question, saved only on the device, with export to a text file
- Text size (A−/A+) and light/dark display
- Share any day by text or email
- Works offline once opened

Install on Android: open the site in Chrome, then tap the menu and choose "Install app" or "Add to Home screen".

An independent study guide; not affiliated with Alcoholics Anonymous World Services.
